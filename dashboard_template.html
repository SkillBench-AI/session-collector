About This Metric

Cognitive Efficiency is a composite measure of interaction efficiency grounded in Cognitive Load Theory. It captures behavioral proxies for how effectively you direct AI coding agents. Values are relative to your own baseline (z-scored within-user). It does not control for task complexity — harder problems naturally require more interaction. A positive trajectory over time is consistent with schema formation: developing more efficient mental models for agent interaction.
